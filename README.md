# UTF — site map & progress portal

Live site (GitHub Pages): https://saicharan13579-source.github.io/UTF/
Editing: on the site, Data entry tab (your name + editor PIN). Data is kept in the UTF Google Sheet (see tools/google-sheet/).

- `index.html` — the published site (built; do not edit by hand)
- `src/` — page template and base data (plots traced from UTF_LAYOUT_1_11, tracker lists of 26-10-2026)
- `data/config.json` — Google Sheet web-app URL used for saving
- `data/snapshots/` — first full record (26-10-2026); daily snapshots continue in the Google Sheet
- `tools/` — build script and the Google Sheet script; see `tools/SYNC.md`
